# Prompt para generar la página gastronómica

```text
Crea una página web completa, elegante y adaptable para un restaurante gastronómico premium llamado “Casa Oliva”, ubicado en La Paz, Bolivia.

Antes de escribir código, revisa los archivos requirements.md y agents.md del proyecto y respeta sus instrucciones.

Tecnologías:
- HTML5, CSS3 y JavaScript ES6.
- Bootstrap 5.3 por CDN oficial.
- Font Awesome 6 por CDN.
- Google Fonts: Playfair Display para títulos y DM Sans para textos.
- No agregues librerías JavaScript pesadas. Usa los componentes nativos de Bootstrap para la navegación móvil y las pestañas del menú.

Estilo visual:
- Cocina de temporada, ingredientes locales y concepto “del huerto a la mesa”.
- Apariencia refinada, cálida y minimalista, con espacios amplios.
- Paleta de crema, verde oliva, carbón y acentos dorados.
- Fotografías gastronómicas grandes como protagonistas, con esquinas sutilmente redondeadas y zoom suave al pasar el cursor.
- Diseño responsive para móvil, tableta y escritorio.

Secciones:
1. Navbar fija y transparente sobre el hero; al desplazarse, debe volverse oscura y sólida. Incluye enlaces a Inicio, Menú, Nuestra casa y Reservas.
2. Hero a pantalla completa con fotografía de fondo, superposición oscura, un eslogan atractivo y botón “Reservar una mesa”.
3. Introducción breve sobre la cocina y los ingredientes locales.
4. Menú con pestañas funcionales de Bootstrap para Entradas, Platos fuertes, Postres y Bebidas. Muestra cada plato en tarjetas con fotografía, descripción, precio en bolivianos y etiquetas como “Vegetariano” o “Favorito de la casa”.
5. Historia y filosofía de la chef en un diseño de dos columnas con fotografía.
6. Formulario de reservas con nombre, correo, teléfono, fecha, hora, número de comensales y notas opcionales. Usa validación visual de Bootstrap y presenta un mensaje de confirmación después de una solicitud válida.
7. Pie de página con horarios, dirección, teléfono y enlaces sociales.

Requisitos de implementación:
- Crea /index.html y /assets/css/restaurant-style.css.
- Agrega comentarios HTML claros antes de cada sección.
- Usa HTML semántico, etiquetas accesibles, textos alternativos en las imágenes y controles con etiquetas asociadas.
- Asegúrate de que los enlaces de navegación y las pestañas funcionen.
- Configura la fecha mínima del formulario para impedir seleccionar días pasados.
- Mantén el código ordenado y fácil de modificar.
- Al terminar, resume los archivos creados y aclara si el formulario necesita conectarse a un backend para recibir reservas.
```
